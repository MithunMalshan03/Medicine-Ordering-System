# Medicine Ordering System

A web-based Medicine Ordering System developed as a university group project using Java, Spring Boot, MySQL, HTML, Tailwind CSS, and JavaScript.

The application supports medicine ordering and inventory management.

## Technologies Used

- **Backend:** Java, Spring Boot, Spring Security, Spring Data JPA
- **Frontend:** HTML, Tailwind CSS, JavaScript
- **Database:** MySQL

## My Contribution – Inventory Management Module

As a member of the development team, I was responsible for implementing the Inventory Management Module.

### Features Developed

- **Add Medicines:** Add new medicines to the inventory.
- **Update Medicines:** Modify existing medicine information.
- **Delete Medicines:** Remove medicines from inventory.
- **View Inventory:** Display available medicines and their stock information.
- **Stock Tracking:** Monitor medicine quantities.
- **Search and Filter:** Find medicines using search and filtering functionality.
- **Low-Stock Alerts:** Identify medicines with low inventory quantities.
- **Expiry Date Management:** Manage and monitor medicine expiry dates.
